# Minesweeper in C

Personal project for fun. Minesweeper created in C using ncurses.

## Dependencies

- `ncurses`

## Running the Game

1. Clone the repository and enter the directory.

```bash
git clone https://github.com/ad030/minesweepy && cd ./minesweepy
```

2. Run `make` to compile the program.

3. Run `./minesweepy` to start the game.

### CONTROLS

- WASD, HJKL (vim style), arrow keys: Navigate menu and board
- Enter: Select item in menu, open square (chording if opening empty square)
- Space, F: Flag selected square
- Backspace: Exit program immediately
